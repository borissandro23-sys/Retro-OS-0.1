# Retro OS roadmap

## Phase 1 — Bootable Linux image
- Debian Live x86_64 base
- Xorg + lightweight window manager
- RetroArch installed and launched as the main interface
- Keyboard and USB gamepad support

## Phase 2 — Console experience
- Retro OS splash and branding
- Direct launch into the game interface
- Hide desktop/window-manager details from normal users
- Shutdown and restart menu

## Phase 3 — Game library
- Scan user-provided ROM folders
- System playlists and artwork
- Per-game launch options
- Save states and configuration persistence

## Phase 4 — Hardware testing
- VirtualBox
- AMD and Intel integrated graphics
- NVIDIA graphics where supported by the chosen driver stack
- Common USB and Bluetooth controllers

## Distribution rules
Do not bundle commercial ROMs or proprietary console BIOS files. Check the license of every Libretro core before redistributing it.
